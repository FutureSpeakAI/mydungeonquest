# The Replay Identity Law (Directive XXII, architect-cured)

**The rule.** A cinematic re-view (Book → overlay, `replay: true`) resolves ONLY what that moment owned, in strict rank:
1. A CLEARED seat (the turn's log names an `imageAssetHash` the media shelf no longer holds) outranks every substitute — still = null, the honest frame line speaks, nothing is borrowed over it.
2. The turn's own plate (`byTurn('paint')`).
3. The BOUND beat's own cover/score (`byKey`) — lawful ONLY when the caller handed a turn-bound `beatIndex` (log rows seal their own `beatIndex`). On replay the codex fallback is DEAD: `beatKeys(camp, -1)` when unbound. The App render site must also not fall back to `codex.beatIndex` for replays.
4. Nothing — procedural art, no cleared claim (an unbound re-view proves nothing).

The LIVE road is untouched: byKey(today's beat) first, own paint second, seen-filtered rung by rung.

**Why:** The Book's replay door once handed `log.dm` alone; identity fell to today's codex beat and the overlay could hang the CURRENT beat's cover over an elder seat (the exact borrow the Fresh Plate Law struck) with the cellar's cleared frame mute. But striking the byKey rung on ALL replays broke the standing seen-bypass law (freshPlates pins "a replay is a re-view, not a new reveal" VIA a beat-cover replay). The lawful line: bind the rung to trustworthy identity instead of striking it.

**How to apply:**
- Any edit to `resolveAssets` or the replay wiring must run the gate trio together: `freshPlates` (seen-bypass + live ladder), `mediaFallback` (live renders), `cellar` (replay identity + cleared frame), plus `book` (the door hands `(dm, log)` — both archive and timeline seats).
- Replay doors hand the WHOLE log row; the table seats `turnRecordHash` + the log's own `beatIndex` into the card state.
- Render-court fixtures: give every plate its OWN MIME subtype (`image/x-<tag>`) — the object-URL stub keys on blob.type, so shared 'image/png' lets a borrowed plate impersonate the lawful one.
- Two directives colliding at one rung is resolved by CONDITIONING the rung on provenance, not deleting it — expect the elder law's gate to red if you over-strike, and treat that red as the reconciliation signal.
